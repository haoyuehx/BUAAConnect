# BUAAConnect

An unofficial command-line VPN client for Beihang University network environments, based on [zju-connect](https://github.com/Mythologyli/zju-connect).

Project initialization only: ACT compatibility has not yet been verified. No BUAAConnect GUI or tested binary release is provided.

See the [Chinese README](README.md) for setup, limitations, attribution and disclaimer. Upstream documentation is preserved in [docs/upstream-readme.md](docs/upstream-readme.md).
